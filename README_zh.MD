# TriCoSphere 机械手 - 中文文档

欢迎使用 **TriCoSphere 机械手** 项目！这是一款创新的模块化协作机械手设计，基于 SolidWorks 进行三维建模。

---

## 📌 项目信息

- **项目名称**：TriCoSphere Hand
- **版本**：1.0
- **项目周期**：2025年3月 - 2025年9月
- **发表会议**：ICRA 2026（已接收）
- **设计软件**：SolidWorks 2024+
- **最后更新**：2026年2月

---

## 💡 项目概述

TriCoSphere 机械手是一个高精度、模块化、易组装的并联机械手系统。第一版本着重于整体设计的**概念验证**和**功能测试**。目前正在进行整体优化工作，敬请持续关注后续版本更新。

**核心特点：**
- ✅ 模块化设计，便于组装和维护
- ✅ 高精度的并联结构
- ✅ 丰富的标准件库
- ✅ 支持多种格式导出

## 📁 文件结构

```
TriCoSphere_hand/
├── TriCoSphere.SLDASM              # 主装配体

│
├── 共轴手装配体/                    # 机械手主体零件

│   ├── 底座.SLDPRT                 # 主底座
│   ├── 基准台座.SLDPRT             # 基准定位台座
│   ├── 中指模块.SLDPRT             # 中指驱动模块

│   ├── 连接件系列/                 # 长边件、短边件、末端杆等
│   ├── 腿部结构/                   # 长腿、短腿及保护盖
│   ├── 指尖.SLDPRT                 # 手指末端执行器
│   └── standard/                   # 标准件库
│       ├── 轴承系列                # 推力、超薄、挡边轴承
│       ├── 紧固件                  # 螺栓、螺母、塞打
│       ├── 球体.SLDPRT             # 标准球体
│       └── 驱动器部件              # 电机及驱动器
│
├── STEP/                           # STEP通用格式
│   └── TriCoSphere.STEP            # 整体装配体导出
│
└── STL/                            # 3D打印格式（预留）
```

## 🔧 文件格式说明

| 格式 | 文件扩展名 | 用途 | 兼容性 |
|------|----------|------|--------|
| SolidWorks 装配体 | `.SLDASM` | 查看装配关系、进行设计修改 | SolidWorks 2024+ |
| SolidWorks 零件 | `.SLDPRT` | 编辑单个零件、参数调整 | SolidWorks 2024+ |
| 标准 CAD 格式 | `.STEP` | 跨平台共享、第三方软件打开 | 通用 CAD 软件 |
| 3D 打印格式 | `.STL` | 3D 打印切片处理 | Cura、PrusaSlicer 等 |

## 🚀 使用指南

### 1️⃣ 查看完整装配体
```
步骤：
1. 用 SolidWorks 打开 TriCoSphere.SLDASM
2. 在装配树中查看零部件关系
3. 使用渲染功能生成高质量演示图
```

### 2️⃣ 编辑单个零件
```
步骤：
1. 打开 共轴手装配体/ 文件夹中的 .SLDPRT 文件
2. 进行参数修改或设计调整
3. 保存后，主装配体会自动更新
```

### 3️⃣ 3D 打印工作流
```
步骤：
1. 选择需要打印的零件
2. 导出为 STL 格式
3. 用切片软件处理（如 Cura、PrusaSlicer）
4. 上传至 3D 打印机
```

### 4️⃣ 跨平台共享
```
步骤：
1. 使用 STEP/TriCoSphere.STEP 文件
2. 可在任何支持 STEP 格式的 CAD 软件中打开
3. 兼容 Fusion 360、FreeCAD、CAD 等
```

## 📝 贡献指南

如需对设计进行改进和优化：

1. **编辑零件**：修改 `共轴手装配体/` 中的 `.SLDPRT` 文件
2. **测试装配**：在主装配体中进行完整验证
3. **更新文档**：修改相关文档和版本信息
4. **导出更新**：生成新的 STEP/STL 文件

**版本管理建议：**
- 保留原始设计文件
- 为重大改进创建版本分支
- 记录改动日志
